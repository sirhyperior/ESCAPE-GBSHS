# 기숙사 탈출하기

밤의 학교 기숙사에서 사감을 피해 탈출하는 한국어 2D 잠입 공포 게임입니다. 5층에서 시작해 복도 끝의 계단을 내려가고, 1층에서 출구로 나가세요. 층마다 복도 형태와 학생 방의 짐 배치가 달라지고, 때때로 휴게실이 나옵니다.

## 실행

이 폴더의 [index.html](index.html)을 PC 브라우저에서 열고 **탈출 시작**을 누르세요. HTML, CSS, JavaScript 파일을 같은 폴더에 두면 바로 실행됩니다.

| 조작 | 동작 |
| --- | --- |
| `↑` `↓` `←` `→` | 이동하고 이동 방향으로 손전등 비추기 |
| `Shift`와 화살표 키 | 스태미나를 사용해 달리기 |

사감은 복도를 오가며 방문 안쪽까지 손전등을 비춥니다. 사감의 빛에 들어가면 발각됩니다. 벽이나 모퉁이를 이용해 시야를 끊고 2.5초 동안 다시 보이지 않으면 추격이 풀립니다. 계단을 내려가면 이전 층 사감의 추격은 끝납니다. 붙잡힌 뒤 다시 시작하면 새 맵의 5층에서 시작합니다.

스태미나를 다 쓰면 지침 상태가 되어 걷는 속도가 줄어듭니다. 회복이 시작된 뒤 7초가 지나 스태미나가 가득 차면 평소 속도로 돌아옵니다.

## 개발

게임은 HTML Canvas와 기본 JavaScript로 동작합니다. Node.js는 자동 테스트를 실행할 때 사용합니다.

```sh
node --test game-core.test.js
```
