# 기숙사 탈출하기

밤의 학교 기숙사에서 사감 선생님을 피해 탈출하는 한국어 2D 잠입 공포 게임입니다. 5층에서 시작해 계단을 내려가고, 1층에서 출구로 나가세요. 주 복도와 우회로는 계단과 출구에 서로 다른 방향으로 이어집니다. 아래층으로 갈수록 맵이 넓어지고 연결 통로가 더 생깁니다. 층마다 복도 형태와 학생 방의 짐 배치가 달라지고, 때때로 휴게실도 나옵니다.

## 실행

이 폴더의 [index.html](index.html)을 PC 브라우저에서 열고 **탈출 시작**을 누르세요. HTML, CSS, JavaScript와 글꼴 파일을 같은 폴더에 두면 바로 실행됩니다.

| 조작 | 동작 |
| --- | --- |
| `↑` `↓` `←` `→` | 이동하고 이동 방향으로 손전등 비추기 |
| `Shift`와 화살표 키 | 스태미나를 사용해 달리기 |
| `Space` | 대사 진행. 플레이 중에는 가까운 아이템을 먼저 줍고, 주울 아이템이 없으면 소지한 액티브 아이템 사용 |

첫 판의 5층 안내가 끝나면 방에서 독백이 시작됩니다. 대사 중에는 게임이 멈추고, 오른쪽 아래의 소리 버튼으로 글자 효과음도 끌 수 있습니다.

5층은 **내 방**에서 시작합니다. 내 방에 들어가면 발각 경고와 추격이 풀리고, 방 안에서는 사감 선생님께 발각되거나 붙잡히지 않습니다. 노란색 **아래층** 계단을 밟고 내려가면 다음 층의 파란색 **위층** 계단 앞에 도착합니다. 위층 계단은 한 칸이며, 양옆으로 지나갈 수 있습니다. 계단을 밟으면 이전 층의 아래층 계단 앞에 돌아옵니다. 지나온 층의 구조는 그대로 남습니다. 1층에서는 초록색 **출구**를 찾으세요. 탈출에 성공하면 **탈출 시작**부터 출구를 통과할 때까지의 소요 시간이 표시됩니다.

사감 선생님들께서는 서로 간격을 두고 순찰하시며 교차로에서 주 복도와 우회로를 오가십니다. 3층부터는 아래층으로 갈수록 순찰과 추격 속도가 조금씩 빨라집니다. 침대나 옷장 같은 가구는 사감 선생님의 손전등과 시야를 가립니다. 가까운 곳에서 가려지지 않은 손전등 불빛은 뒤를 보고 있을 때도 희미하게 보입니다. **발각 직전** 경고가 뜨면 0.75초 안에 사감 선생님의 시야에서 벗어나세요.

3층, 2층, 1층 복도에는 CCTV가 각각 2대, 4대, 6대씩 있습니다. 천천히 회전하는 청록색 스캔에 닿으면 가장 가까이 계신 사감 선생님께 즉시 발각되고, 스캔이 붉게 표시됩니다. 스캔이 지나가기를 기다리거나 연결 통로로 우회할 수 있습니다. EMP를 사용하면 같은 층의 CCTV와 손전등이 잠시 꺼집니다.

발각 중에는 추격하거나 수색하시는 사감 선생님의 위치가 어둠 속에서도 표시됩니다. 화면 밖에 계시면 가장자리 화살표로 방향을 알 수 있습니다. 벽이나 가구를 이용해 2.5초 동안 시야를 끊으면 추격이 풀립니다. 계단으로 층을 옮기면 이전 층의 추격은 끝납니다. 붙잡힌 뒤 다시 시작하면 새 맵의 5층에서 시작합니다.

기본 스태미나가 가득 차면 4초 동안 달릴 수 있습니다. 스태미나를 다 쓰면 지침 상태가 되어 걷는 속도가 줄어듭니다. 회복이 시작된 뒤 7초가 지나 스태미나가 가득 차면 평소 속도로 돌아옵니다.

아이템에 가까이 가면 8비트 안내창에 아이콘, 이름, 설명이 표시되며, 주우면 바로 닫힙니다. 내 방 이외의 일반 방에는 18% 확률로 아이템이 하나 나옵니다. 휴게실은 층마다 33% 확률로 생기며, 아이템이 항상 하나 있습니다. 스태미나 바 아래에 패시브와 액티브 슬롯이 하나씩 있습니다. 패시브는 들고 있는 동안 효과가 적용되고, 액티브 소모품은 사용하면 슬롯에서 사라집니다. 같은 종류의 아이템을 주우면 원래 들고 있던 아이템이 주운 자리에 떨어집니다.

스태미나가 회복되는 동안 게이지가 빛나고, 가득 차면 캐릭터 주변에 픽셀 입자가 퍼집니다. 아이템으로 속도가 올라간 채 움직이면 속도선이 나타납니다. 소지품 칸 아래에 적용 중인 아이템 효과와 시간 제한이 있는 효과의 남은 시간이 표시됩니다.

움직일 때 발소리가 나고 달리거나 지치면 숨이 가빠집니다. 발각 중에는 심장 박동이 들립니다. 오른쪽 아래의 **소리 켜짐/꺼짐** 버튼으로 효과음을 조절할 수 있습니다.

## 개발

게임은 HTML Canvas와 기본 JavaScript로 동작합니다. Node.js는 자동 테스트를 실행할 때 사용합니다.
아이템 이름, 종류, 설명, 픽셀 아이콘과 효과 표시 색·문구는 [game-items.js](game-items.js)에서 관리합니다. 새 패시브 아이템은 소지 시 기본 효과 문구와 픽셀 연출이 적용됩니다. 새 액티브 아이템의 사용 분기에는 필요에 따라 효과 문구 키와 실제 효과의 종료 시점을 지정할 수 있습니다. 성공한 사용에 지정 문구가 없으면 아이템 이름으로 표시합니다.

대사에는 공개 도메인으로 배포된 둥근모꼴+Fixedsys 웹폰트 `DungGeunMo.woff`를 사용합니다. [눈누 웹폰트 안내](https://noonnu.cc/font_page/250)

게임 UI와 맵 표지에는 흥국생명의 이서윤체 웹폰트 `LeeSeoyun.woff`를 사용합니다. [눈누 웹폰트 안내](https://noonnu.cc/font_page/872), [흥국생명 이용 조건](https://www.heungkuklife.co.kr/jsps/front/company/ci/digit-hand-font-info.jsp)
