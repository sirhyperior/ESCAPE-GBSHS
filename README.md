# 기숙사 탈출하기

밤의 학교 기숙사에서 사감을 피해 탈출하는 한국어 2D 잠입 공포 게임입니다. 5층에서 시작해 복도 끝의 계단을 내려가고, 1층에서 출구로 나가세요. 아래층으로 갈수록 맵이 넓어집니다. 층마다 복도 형태와 학생 방의 짐 배치가 달라지고, 때때로 휴게실이 나옵니다.

## 실행

이 폴더의 [index.html](index.html)을 PC 브라우저에서 열고 **탈출 시작**을 누르세요. HTML, CSS, JavaScript 파일을 같은 폴더에 두면 바로 실행됩니다.

| 조작 | 동작 |
| --- | --- |
| `↑` `↓` `←` `→` | 이동하고 이동 방향으로 손전등 비추기 |
| `Shift`와 화살표 키 | 스태미나를 사용해 달리기 |

사감은 서로 간격을 두고 복도를 순찰하며 방문 안쪽까지 손전등을 비춥니다. 방문 옆 벽에 가려진 방 안 모서리에 몸을 숨길 수 있습니다. 벽에 가려지지 않은 가까운 사감의 불빛은 뒤를 보고 있을 때도 희미하게 보입니다. **발각 직전** 경고가 뜨면 0.75초 안에 사감의 시야에서 벗어나세요.

발각 중에는 추격하거나 수색하는 사감의 위치가 어둠 속에서도 표시되며, 화면 밖 사감은 가장자리의 화살표로 방향을 알 수 있습니다. 벽이나 모퉁이를 이용해 2.5초 동안 시야를 끊으면 추격이 풀립니다. 계단을 내려가면 이전 층 사감의 추격은 끝납니다. 붙잡힌 뒤 다시 시작하면 새 맵의 5층에서 시작합니다.

스태미나가 가득 차면 최대 4초 동안 달릴 수 있습니다. 스태미나를 다 쓰면 지침 상태가 되어 걷는 속도가 줄어듭니다. 회복이 시작된 뒤 7초가 지나 스태미나가 가득 차면 평소 속도로 돌아옵니다.

움직일 때 발소리가 나고 달리거나 지치면 숨이 가빠집니다. 발각 중에는 심장 박동이 들립니다. 오른쪽 아래의 **소리 켜짐/꺼짐** 버튼으로 효과음을 조절할 수 있습니다.

## 개발

게임은 HTML Canvas와 기본 JavaScript로 동작합니다. Node.js는 자동 테스트를 실행할 때 사용합니다.

```sh
node --test game-core.test.js
```
